# いろ検クエスト

色彩検定（3級・2級レベル）の内容を、スマホで遊びながら覚えるクイズゲームです。
`index.html` 1ファイルで動きます（ビルド不要）。

## 遊び方
- `index.html` をブラウザで開く、または GitHub Pages で公開してスマホからアクセス
- 10問1セット。正解でスコア＋スピードボーナス＋コンボボーナス

## アクションモード
| モード | 内容 |
| --- | --- |
| カラーラッシュ | 60秒。降ってくる色から、ルール（暖色・寒色・明清色・dkトーン…）に合う色だけをタップ |
| トーンマップ・ダッシュ | 出てきた色のトーンを、トーン図上の位置で時間内にタップ。レベルが上がるほど速くなる |
| 色相環スナイプ | 回転する色相環で「同じ色相」や「補色」の位置をタップ |
| 波長チューナー | お題の色や「短波長域」「紫外線」などに合う位置をスペクトル上でタップ |
| 分光カーブ・リーダー | 分光反射率曲線から、その物体が何色に見えるかを当てる |
| 目のパーツタッチ | 目の断面図で、角膜・水晶体・網膜・盲点などのパーツをタッチ |
| 錐体シグナル | L・M・S 錐体の反応グラフから、見える色を当てる |
| 色かるた | 読まれた慣用色名の札を、相手のバーが満ちる前に取る |
| ミキシング・ラボ | R・G・B の光／C・M・Y のインクを選んでお題の色を作る（加法・減法混色） |
| 錯視ジャッジ | 対比や同化の図で、中央の色が「同じ」か「違う」かを見抜く |
| 安全色シグナル | 標識に合う JIS 安全色を6色から選ぶ |
| 配色ジャッジ | 配色を見て、トーンオントーン・カマイユ・トリコロールなどの技法名を当てる |
| コーデ診断 | コーデの配色から、ロマンティック・モダンなどのファッションイメージを当てる |
| ライト＆ルーム | 場面に合う色温度や、ベース／アソート／アクセントカラーの役割を選ぶ |

ライフ3つ・コンボ倍率・スコアのベスト記録つき。フィールドは色を見比べやすい中性グレーです。

## クイズモード
| モード | 内容 |
| --- | --- |
| ミックス10問 | 全ジャンルからランダム |
| ジャンル別・級別 | 13ジャンル／3級・2級・UC級の範囲から10問。ジャンルごとの正答率と苦手ジャンルを表示 |
| 知識クイズ | 全ジャンルの知識問題（約170問）からランダム |
| PCCSトーン当て | 4色に共通するトーン（v / b / dp / ltg …）を当てる |
| 色相環チャレンジ | 補色・色相名・色相記号・色相差による配色 |
| 慣用色名 | 色⇔名前（鴇色・浅葱色・ボルドーなど42色） |

### ジャンル
色の基本／光の性質／目と脳のしくみ／色の見え方／混色／PCCS／表色系と色名／色の心理と効果／配色と色彩調和／ファッション／インテリア・商品・環境／色彩と文化／照明と測色／ユニバーサルデザイン／慣用色名

「目と色の見え方」では対比・同化・リープマン効果などを実際に見て答える問題、「混色」では色光・色料を混ぜた結果を色で選ぶ問題も出ます。

「まなぶ」では、色相を切り替えられるトーン図・PCCS 24色相環・配色技法・混色・慣用色名図鑑・安全色・色温度・インテリア配色比率・光と目のしくみ（スペクトル、目の断面図、錐体と杆体、色覚の説）を見られます。

画面の色は PCCS 色票・JIS 慣用色名の近似値です。

## セルフチェック
`node tests/selfcheck.js`（Playwright と Chromium が必要）で、問題データの監査（正解が1つだけか、選択肢の重複、色の見分けやすさ）、全アクションゲームを正解し続けるボット、小さい画面のレイアウト確認をまとめて実行します。
