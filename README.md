# いろ検クエスト

色彩検定（3級・2級レベル）の内容を、スマホで遊びながら覚えるクイズゲームです。
`index.html` 1ファイルで動きます（ビルド不要）。

## 遊び方
- `index.html` をブラウザで開く、または GitHub Pages で公開してスマホからアクセス
- 10問1セット。正解でスコア＋スピードボーナス＋コンボボーナス

## アクションモード
| モード | 内容 |
| --- | --- |
| カラーラッシュ | 60秒。降ってくる色から、ルール（暖色・寒色・明清色・dkトーン…）に合う色だけをタップ |
| トーンマップ・ダッシュ | 出てきた色のトーンを、トーン図上の位置で時間内にタップ。レベルが上がるほど速くなる |
| 色相環スナイプ | 回転する色相環で「同じ色相」や「補色」の位置をタップ |

ライフ3つ・コンボ倍率・スコアのベスト記録つき。フィールドは色を見比べやすい中性グレーです。

## クイズモード
| モード | 内容 |
| --- | --- |
| ミックス10問 | 全ジャンルからランダム |
| ジャンル別・級別 | 13ジャンル／3級・2級・UC級の範囲から10問。ジャンルごとの正答率と苦手ジャンルを表示 |
| 知識クイズ | 全ジャンルの知識問題（約170問）からランダム |
| PCCSトーン当て | 4色に共通するトーン（v / b / dp / ltg …）を当てる |
| 色相環チャレンジ | 補色・色相名・色相記号・色相差による配色 |
| 慣用色名 | 色⇔名前（鴇色・浅葱色・ボルドーなど42色） |

### ジャンル
光と色の基本／目と色の見え方／混色／PCCS／表色系と色名／色の心理と効果／配色と色彩調和／ファッション／インテリア・商品・環境／色彩と文化／照明と測色／ユニバーサルデザイン／慣用色名

「目と色の見え方」では対比・同化・リープマン効果などを実際に見て答える問題、「混色」では色光・色料を混ぜた結果を色で選ぶ問題も出ます。

「まなぶ」では、色相を切り替えられるトーン図・PCCS 24色相環・配色技法・混色・慣用色名図鑑・安全色・色温度・インテリア配色比率を見られます。

画面の色は PCCS 色票・JIS 慣用色名の近似値です。
